Retrieve a specified region from a URL with tabix or bcftools

Each file has a tabix index (.tbi). By passing a file URL and a region to a tabix-compatible tool, you can retrieve only the required region without first downloading an entire chromosome file.

Retrieve allele frequencies from VCF

You can pass the URL of a BGZF-compressed VCF directly to bcftools view. Use -r to specify the region and -H to omit the VCF header. The following JGA-WGS example uses chr12 to match the chromosome name stored in the VCF.

$ bcftools view -H \
  -r 'chr12:111803962-111803962' \
  'https://grch38.togovar.org/downloads/release/current/grch38/frequency/vcf/jga_wgs/jga_wgs.chr12.grch38.vcf.gz'

# Example output
chr12	111803962	.	G	A	.	PASS	AC=1784;AN=6136;AAC=276;ARC=1232;AOC=0;RRC=1560;ROC=0;OOC=0

Retrieve annotations as JSON

For GRCh37 and GRCh38 JSON-in-TSV files, you can use tabix to retrieve annotations for a specified region. The output has three columns: chromosome, position, and JSON. Add cut -f3 to print only the JSON column. Do not include the chr prefix in the region's chromosome name. The following example uses jq to select and format key fields from the response. The conventional TSV format remains available.

GRCh38 example (chr12:111803962)

$ tabix \
  'https://grch38.togovar.org/downloads/release/current/grch38/annotation/json_tsv/chr12_molecular_annotation_json.tsv.gz' \
  '12:111803962-111803962' \
  | cut -f3 \
  | jq '{id, type, chromosome, position, reference, alternate, most_severe_consequence}'

# Example output
{
  "id": 47264307,
  "type": "SNV",
  "chromosome": "12",
  "position": 111803962,
  "reference": "G",
  "alternate": "A",
  "most_severe_consequence": "missense_variant"
}
