tabix・bcftoolsでURLから指定領域だけを取得

各ファイルにはtabix index（.tbi）が用意されています。tabix対応ツールへファイルのURLと領域を指定すると、染色体ごとのファイル全体を事前にダウンロードせず、必要な領域だけを取得できます。

アレル頻度（VCF）の取得

BGZF圧縮されたVCFのURLは、 bcftools viewへ直接指定できます。-rで取得領域を指定し、-HでVCFヘッダーを省略します。次のJGA-WGSの例では、VCF内の染色体名に合わせてchr12を指定します。

$ bcftools view -H \
  -r 'chr12:111803962-111803962' \
  'https://grch38.togovar.org/downloads/release/current/grch38/frequency/vcf/jga_wgs/jga_wgs.chr12.grch38.vcf.gz'

# 出力例
chr12	111803962	.	G	A	.	PASS	AC=1784;AN=6136;AAC=276;ARC=1232;AOC=0;RRC=1560;ROC=0;OOC=0

アノテーション（JSON）の取得

GRCh37およびGRCh38では、JSONを格納したTSV形式のアノテーションをtabixで領域指定して取得できます。出力は「染色体、位置、JSON」の3列で、cut -f3を加えるとJSON列だけを出力できます。領域の染色体名にはchrを付けません。次の例では、jqでレスポンスから主な項目だけを整形しています。従来のTSV形式も引き続き提供します。

GRCh38の例（chr12:111803962）

$ tabix \
  'https://grch38.togovar.org/downloads/release/current/grch38/annotation/json_tsv/chr12_molecular_annotation_json.tsv.gz' \
  '12:111803962-111803962' \
  | cut -f3 \
  | jq '{id, type, chromosome, position, reference, alternate, most_severe_consequence}'

# 出力例
{
  "id": 47264307,
  "type": "SNV",
  "chromosome": "12",
  "position": 111803962,
  "reference": "G",
  "alternate": "A",
  "most_severe_consequence": "missense_variant"
}
