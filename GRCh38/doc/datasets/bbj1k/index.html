BBJ1K dataset

Summary

The NBDC Human Database/Japanese Genotype-phenotype Archive (JGA) reanalyzed the individual-level WGS data in JGAD000220 from 1,026 participants enrolled in BioBank Japan between fiscal years 2003 and 2007 and produced JGAD000758, a joint-called aggregate VCF dataset containing individual-level genotypes. TogoVar provides the allele frequencies and genotype counts calculated from JGAD000758 as the dataset-specific frequency dataset “BBJ1K” in JGA-WGS.

  • Sample size: 1,026
  • Number of alternate alleles searchable in TogoVar: 44,694,482

Data processing method

  • Explanation: Whole genome sequencing data processing (germline)
  • Workflow Source Code (jga-analysis): https://github.com/ddbj/jga-analysis
